## 🎯 ¿Qué es?

**ErBolamm Studio** es una suite creativa multiplataforma (macOS, Windows, Linux, mobile) que convierte un proyecto en contenido promocional listo para redes sociales y tiendas oficiales.

Es un **pipeline creativo completo**:

```
📥 Proyecto → 🎵 Música → 🎬 Animación → 🗣️ Voz → 📱 Capturas Tiendas → 📦 Publicación
```

---

## ✨ Features principales

- 🎵 **Music Studio**: Generación procedural con Strudel y Tone.js para música de fondo.
- 🎬 **Animation Studio**: Templates HTML animados y renderizado a video MP4 (vertical/horizontal).
- 🗣️ **Voice Studio**: Síntesis y narración en 6 idiomas (ES, EN, PT, FR, DE, IT).
- 📱 **Store Screenshot Generator**: Generación automática de capturas para App Store (iPhone 6.5", 6.7", iPad 13") cumpliendo la normativa Apple Guideline 2.3.3.
- 📝 **Release Notes de 1-Clic**: Textos formateados para Google Play Console y App Store Connect por idioma.
- 🧠 **Orchestrator**: Pipeline secuencial de 7 agentes con selector multi-proveedor de IA (DeepSeek, MiniMax, Claude, OpenAI, Gemini, Groq, NVIDIA).

## 🚀 Cómo empezar

```bash
# 1. Clonar el repositorio
git clone https://github.com/erbolamm/erbolamm-studio.git
cd erbolamm-studio

# 2. Instalar dependencias
flutter pub get

# 3. Ejecutar la aplicación
flutter run
```
